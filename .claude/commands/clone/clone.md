# 클론 코딩

예시 이미지를 보고 똑같은 화면을 클론 코딩해 줘.

## 입력

### Few-shot 예시 이미지

<!-- $1: 첫 번째 인자. 클론할 예시 이미지 경로 -->
$1

## 작업 순서

1. **이미지 분석:** `$1` 이미지를 읽고 다음을 파악한다.
   - 전체 레이아웃 (헤더, 본문, 사이드바, 푸터 등 영역 구분)
   - 컴포넌트 구성 (버튼, 입력창, 카드, 리스트, 아이콘 등)
   - 스타일 (색상, 폰트, 글자 크기, 간격, 테두리, 그림자, 모서리 둥글기)
   - 이미지 속 텍스트와 이미지 요소
2. **클론 코딩:** 분석 결과를 바탕으로 이미지와 최대한 같은 모양으로 화면을 구현한다.
   - 텍스트는 이미지에 보이는 내용을 그대로 사용한다.
   - 사진/일러스트처럼 코드로 만들 수 없는 요소는 같은 크기의 자리 표시 영역으로 대신한다.
3. **결과 보고:** 만든 파일, 그리고 이미지와 다르게 구현한 부분(있다면)을 알려준다.

## 주의 사항

- 이미지 경로가 없거나 이미지를 읽을 수 없으면 작업하지 말고 알려준다.
- 프로젝트에 이미 쓰는 프레임워크/스타일 방식이 있으면 그것을 따른다.
